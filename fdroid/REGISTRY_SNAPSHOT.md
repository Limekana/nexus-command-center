**2026-07-20 — LimeLog v1.8.1 / StudyDesk v1.5.2 + NCC v1.7.0 APK republished (Builder).** Fixes the two root causes behind `FD-REPRODUCIBLE-MISMATCH` (diagnosed same day — see Open Blockers for the full evidence).
- **NCC v1.7.0 — no code change, APK republished.** The GitHub Release asset was built from **stale** `android/app/src/main/assets/public/`; Gradle packaged an old bundle because `npm run build && npx cap sync android` was never re-run before `assembleRelease`. Tag and source unchanged. **Process rule going forward: always `npm run cap:sync` (build + sync) immediately before `assembleRelease` — never assemble on top of whatever is already in the assets dir.**
- **LimeLog v1.8.1** (versionCode 17): `src/lib/supabase.ts` read `VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY` from `import.meta.env` with **no fallback**. Now uses the `env || hardcoded` pattern NCC and StudyDesk already had. Verified: a no-`.env` Debian/Node 22 container build is now **byte-identical** to the local build. Also added `android/key.properties` to `.gitignore` (keystore password was untracked but unignored).
- **StudyDesk v1.5.2** (versionCode 11): closes `STUDYDESK-UNSCOPED` — the uncommitted `develop` work was audit fixes, not stray work. Ships the `merge.js` LWW fix (compared timestamps as **strings**; local `...sssZ` vs Postgres `...+00:00` meant two writes in the same second could clobber the newer edit — a real data-loss bug), midnight-rollover fix (`TODAY` was frozen at module load), hydrate guards, and the eslint `android/` ignore. Build gate clean.
- **Determinism proven, not assumed:** clean `npm ci` + build is byte-identical across Windows/Debian and Node 22/24 (verified in Docker). The CTO's Node-drift and path-separator hypotheses were both tested and **falsified** — `node_modules` matched `package-lock.json` exactly (0 drift) in both repos. F-Droid's builds were correct; ours were wrong.
